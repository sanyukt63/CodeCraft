# Accessibility Guide

CodeCraft should remain usable with keyboard, screen readers, and small screens.

## Checklist

- Use semantic headings in page order.
- Keep form controls labelled and keyboard accessible.
- Provide visible focus states.
- Use sufficient text contrast.
- Add meaningful `alt` text to informative images.
- Avoid using color alone to communicate state.
- Test layouts at narrow mobile widths.

## Before a UI change

1. Navigate the changed flow with only a keyboard.
2. Check focus order and visible focus.
3. Test the page at mobile and desktop widths.
4. Verify labels, buttons, and links are descriptive.
