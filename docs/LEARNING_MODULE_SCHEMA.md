# Learning Module Schema

A learning module should have stable identifiers and predictable content fields.

Suggested fields:

- `id`: stable module identifier
- `title`: learner-facing title
- `objective`: expected learning outcome
- `content`: lesson explanation and examples
- `practice`: linked exercise or challenge
- `quiz`: optional knowledge check
- `estimatedMinutes`: approximate completion time

Validate required fields before rendering a module, and keep identifiers stable when titles change.
