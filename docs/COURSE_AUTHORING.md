# Course Authoring Guide

Use this guide when adding a new learning module to CodeCraft.

## Recommended module structure

1. Learning objective
2. Short explanation
3. Worked example
4. Practice task
5. Quiz or checkpoint
6. Progress update

## Content checklist

- Keep one primary concept per lesson.
- Prefer small examples before larger problems.
- Explain expected output for code examples.
- Include at least one practice task.
- Add a clear completion condition.
- Keep terminology consistent with existing modules.

## Quality check

Before publishing, verify the lesson on desktop and mobile, test every linked resource, and confirm that examples match the explanation.
